Data Directory Placeholder

The raw Olist source data files are excluded from this repository to keep file sizes clean and follow data privacy best practices.

How to get the data:

1. Download the transaction files directly from the **[Official Kaggle Olist E-Commerce Dataset](https://kaggle.com "Kaggle Olist Dataset Page")**.
2. Unpack the compressed zip archive structure.
3. Drop the raw `.csv` files straight into this local `/data/` subdirectory on your machine to run the automated python pipeline scripts.
